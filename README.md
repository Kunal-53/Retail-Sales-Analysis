# Data Analyst Project: Customer Segmentation

## Project Overview
This project focuses on analyzing customer purchasing behavior and identifying valuable customer segments using SQL, Python, and Power BI. The goal is to transform raw sales data into meaningful business insights.

## Tools & Technologies
- **SQL:** Data cleaning and data preparation
- **Python:** RFM analysis and customer segmentation
- **Power BI:** Interactive dashboard and data visualization

## Project Workflow
1. **Data Cleaning using SQL**
   - Removed invalid and missing records.
   - Filtered out invalid transactions.
   - Prepared the dataset for analysis.

2. **Customer Segmentation using Python**
   - Calculated Recency, Frequency, and Monetary (RFM) values.
   - Assigned customer scores.
   - Segmented customers based on purchasing behavior.

3. **Dashboard Development using Power BI**
   - Created interactive visualizations.
   - Presented customer segments and sales performance.
   - Developed a dashboard to support business decision-making.

## Key Objectives
- Understand customer purchasing patterns.
- Identify high-value and inactive customers.
- Analyze customer behavior using RFM analysis.
- Present actionable insights through an interactive dashboard.
